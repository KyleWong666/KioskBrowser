# KioskBrowser 公共场所 Web 展示浏览器 — 使用说明书

> **版本：** v1.1.0
> **编制日期：** 2026-08-20
> **适用产品：** KioskBrowser（Kiosk 展示终端软件）
> **适用场景：** 政务大厅、医院、商场、展馆等公共场所的无人值守 Web 交互终端

---

## 1. 产品简介

KioskBrowser 是一款专为公共场所触屏终端设计的专用浏览器，基于 WebView2(Chromium 内核）运行，具备：

- **霸屏锁定**：全屏置顶、禁止退出、屏蔽系统快捷键，7×24 小时无人值守运行
- **自定义软键盘**：英文/符号/中文拼音输入，替代体验差的系统虚拟键盘
- **语音输入**：本地离线语音识别（无需联网、无需云服务），支持领域热词
- **模拟登录**：目标网页自动填表登录
- **隐蔽管理入口**：左上角连击触发设置页，可加装密码门
- **进程守护**：独立守护进程，崩溃/卡死自动重启，开机自启
- **远程管理（付费版）**：后台批量管理终端（改 URL、换词库、截屏、重启等）
- **单机版永久免费，无广告**；远程管理 API 为付费功能，扫码付费激活

### 1.1 版本说明

| 版本 | 功能 |
|---|---|
| 单机版（免费） | 全部本地功能：霸屏浏览、软键盘、拼音输入、语音输入、词库、模拟登录、守护进程 |
| 付费版（扫码激活） | 单机版全部功能 + 远程管理 API（见第 6 章） |

### 1.2 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 (1809+) / Windows 11,x64 |
| 运行时 | .NET 6（自包含发布无需安装）+ WebView2 Runtime（安装包自动检测） |
| 硬件 | 建议 4GB+ 内存；语音输入需麦克风；管理员操作建议接物理键盘（非必需） |
| 网络 | 加载目标网页所需网络；语音输入**不需要**联网 |

## 2. 安装与部署

### 2.1 安装步骤

1. 将发布目录（含 `KioskBrowser.exe`、`KioskWatchdog.exe`、`config_default.json` 等）拷贝到终端，例如 `C:\KioskBrowser\`
2. **以管理员身份**运行 `install.bat`，脚本将自动：
   - 检测 WebView2 Runtime（缺失时提示下载地址）
   - 写入默认配置
   - 注册开机计划任务（登录后 30 秒启动守护进程）
   - 立即启动守护进程（守护进程拉起主程序）
3. 首次启动后进入霸屏模式，按第 3 章完成初始化配置

### 2.2 卸载

以管理员身份运行 `uninstall.bat`：删除计划任务并停止进程。
配置文件保留在 `%LocalAppData%\KioskBrowser\`，如需彻底清除请手动删除该目录。

### 2.3 目录结构

| 位置 | 内容 |
|---|---|
| 安装目录 | `KioskBrowser.exe`（主程序）、`KioskWatchdog.exe`（守护进程） |
| `%LocalAppData%\KioskBrowser\config.json` | 主配置（损坏时自动用 `.bak` 恢复） |
| `%LocalAppData%\KioskBrowser\logs\` | 运行日志（按天滚动，保留 90 天） |
| `%LocalAppData%\KioskBrowser\models\` | 语音模型（zh2025 / large） |
| `%LocalAppData%\KioskBrowser\hotwords.txt` | 语音热词文件（自动生成） |

## 3. 初始配置

### 3.1 进入设置页

在屏幕**左上角区域内连续快速点击 8 次**（默认 80×80 像素区域，间隔 ≤0.8 秒），设置面板居中弹出。

- 点击间隔超时或偏离区域，序列自动重置
- 连续 5 次错误序列，锁定 60 秒（防公众暴力尝试）
- 可配置**入口密码**：开启后连击通过需再输密码（第 3.4 节）

### 3.2 必配项

| 配置项 | 说明 |
|---|---|
| 目标 URL | 要展示的网页地址（`http://` 或 `https://` 开头） |

修改后点「**保存并重启**」生效。

### 3.3 模拟登录（可选）

目标页面需要登录时启用：

| 配置项 | 说明 | 示例 |
|---|---|---|
| 启用模拟登录 | 开关 | — |
| 登录用户名 / 密码 | 凭据（AES-256-GCM 加密存储，密钥绑定本机硬件，配置文件拷走无法解密） | — |
| 用户名/密码/提交按钮选择器 | 页面元素的 CSS 选择器 | `#username` `#password` `#login-btn` |

工作机制：页面加载后轮询等待表单出现（默认最长 10 秒）→ 填值并触发 `input/change` 事件（兼容 React/Vue/Angular)→ 点击提交 → 表单消失判定成功。连续 3 次失败自动暂停并告警（可配 Webhook)，防止账户锁定。

### 3.4 设置页入口密码（可选）

- 「设置入口新密码」：填写即设置，留空保持不变
- 「清除设置入口密码」：勾选后保存即移除
- 密码以 SHA256 哈希存储，不可逆
- 启用后连击进入设置前需先通过密码门（全屏密码键盘，触屏可输）；连续 5 次错误锁定 60 秒

### 3.5 霸屏模式

设置页「霸屏模式」开关（默认开启）：

| 状态 | 行为 |
|---|---|
| 开启（默认） | 全屏置顶无边框、禁关闭、拦截系统快捷键（Win/F1-F12/Alt+Tab/Ctrl+W 等）、屏蔽任务管理器呼出键 |
| 关闭 | 普通窗口模式：可调大小、可关闭、显示任务栏、不拦系统键；窗口右上角出现「⚙ 设置」按钮并支持 `Ctrl+Alt+S` 快捷键——**供测试/调试使用** |

> 注意：`Ctrl+Alt+Del` 用户态无法拦截，如需屏蔽请配合组策略（计算机配置 → Windows 设置 → 安全设置 → 本地策略 → 安全选项 → 交互式登录）。

### 3.6 其他设置项

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 导航白名单 | 逗号分隔域名，非空时仅允许访问这些域名（含子域） | 空（不限） |
| 触发区边长 | 左上角触发区像素 | 80 |
| 连击次数 | 进入设置所需点击次数 | 8 |
| 键盘高度 | 软键盘占屏幕高度百分比 | 35% |
| 告警 Webhook | 异常/重启时 HTTP POST 通知（可空） | 空 |
| 恢复默认 | 全部配置恢复出厂值（二次确认） | — |

按钮说明：「保存并重启」立即生效；「仅保存」下次启动生效；「取消」丢弃修改；「退出 Kiosk」完全退出软件（同时停止守护进程，二次确认）。

## 4. 软键盘与中文输入

### 4.1 基本行为

- 点击网页中的输入框 → 软键盘自动从底部弹出；点击页面空白/「隐藏键盘」→ 收起
- 系统自带虚拟键盘（TabTip）被自动屏蔽，不会弹出
- 输入框会自动避开键盘遮挡（页面视口随之收缩）

### 4.2 键盘布局

- 字母区标准 QWERTY，左右双 **Shift** 联动
- `#+=` 切换符号页（显示 `ab` 返回字母）
- `Enter` 回车：单行输入框提交表单、多行框换行
- `Tab` 跳到下一个输入框；`空格`；`⌫` 退格
- 语音输入见第 5 章

### 4.3 中文拼音输入

点左下角「**中**」键切换中文模式（按钮变蓝显示 EN 再点切回）：

- 输入拼音字母，键盘**上方悬浮候选栏**实时显示候选
- **整词连拼**：`nihao` → 你好、`zhongguo` → 中国
- **首字母简拼**：`zg` → 中国、`bj` → 北京
- **前缀提示**：输到一半即出词，如 `niha` → 你好
- 点候选字直接上屏；`◀ ▶` 翻页或**左右滑动**候选栏翻页
- 空格 = 选第一个候选；回车 = 拼音字母原样上屏；中文标点自动全角（`,`→`，`)
- 字库 3.6 万字（高频字在前），词库 18.5 万词（按真实词频排序）

### 4.4 词库（行业限定）

设置页「拼音词库」多选 + 「自定义词库」（一行一词）：

| 词库 | 内容 | 适用 |
|---|---|---|
| 通用词库 | 18.5 万日常词组 | 默认 |
| 政务服务 | 身份证、户口本、居住证、公积金… | 政务大厅 |
| 医疗健康 | 挂号、科室、化验、医保报销… | 医院 |
| 商场零售 | 收银台、会员、退换货、楼层… | 商场 |
| 工业工控 | 变频器、伺服电机、PLC、流水线、稼动率、点检… | 工厂/工控 |
| 自定义词库 | 管理员自填，如"星创大厅""一窗通办窗口" | 各行业 |

- **领域词/自定义词候选置顶**（全拼、首字母、前缀都能命中）
- 勾掉「通用词库」→ 候选只剩领域词 + 自定义词 + 单字，实现**输入范围限定**
- 词库不能为空：至少勾选一个词库或填写自定义词，否则无法保存

## 5. 语音输入

### 5.1 使用

1. 设置页勾选「启用语音输入」并选择模型档位，保存并重启
2. 首次启用需联网下载模型一次（之后完全离线运行）
3. 点输入框弹出键盘 → **按住「按住说话」键**（变红）→ 说话 → 松开 → 识别结果直接上屏
4. 识别状态（正在聆听/识别中/未识别到语音）显示在候选栏

### 5.2 模型档位

| 档位 | 体积 | 类型 | 热词 | 特点 |
|---|---|---|---|---|
| 中文2025（推荐） | ~165MB | 流式 | ✓ | 说话过程实时出中间结果；支持热词提升领域词准确率 |
| 大模型 paraformer | ~230MB | 非流式 | ✗ | 精度最高；松开后一次性出结果；不支持热词 |

> **热词说明**：热词 = 勾选的专业词库（政务/医疗/商场/工业）+ 自定义词库。仅「中文2025」档生效；大模型引擎（sherpa-onnx paraformer）本身不支持热词，但其精度通常不需要热词辅助。

- 模型档位在设置页下拉选择，未下载的档位在保存重启后自动联网下载（hf-mirror 国内镜像）
- 低配置终端（2GB 内存工控机）建议实测后再定档位；各档位实测：中文2025 内存约 220MB、解码 13 倍实时速

### 5.3 环境要求与建议

- 需要可用的麦克风（Windows 默认录音设备）
- 内置 AGC 自动增益，轻声/远讲可识别；公共嘈杂环境建议按住后靠近麦克风说话
- 识别在**本地完成，不上传任何音频**，满足公共场所隐私要求

## 6. 远程管理 API（付费版）

单机版永久免费、无广告；远程管理能力需**扫码付费激活**（按台/按年订阅）。

### 6.1 激活流程

1. 设置页填写「管理后台 URL」并勾选「启用远程管理」→ 保存并重启
2. 终端自动向后台注册（上报 MAC 地址、主机名、软件版本）
3. 设置页「付费激活」行点「**扫码激活**」→ 弹窗显示收款二维码（金额由后台套餐决定）
4. 微信/支付宝扫码付款 → 支付平台回调后台 → 终端轮询到支付成功 → 自动激活
5. 设置页激活状态变为「已激活（有效期至 xxxx-xx-xx）」，远程命令即刻可用

> 到期未续费：后台自动将终端回落为 free，远程命令停止响应（本地单机功能不受影响）。

### 6.2 协议接口（后台对接规范）

终端为 HTTP 客户端，JSON over POST：

```
POST {serverUrl}/api/terminal/register
  → {mac, hostname, version, licenseKey, homeUrl, modelSize}
  ← {"ok":true, "plan":"paid"|"free", "expiresAt":"2027-08-20"}

POST {serverUrl}/api/terminal/heartbeat        （每 15 秒，可配）
  → {mac, licenseKey, uptime}
  ← {"ok":true, "plan":"paid", "commands":[{"id":"c1","type":"setUrl","payload":{...}}]}

POST {serverUrl}/api/terminal/command-result   （命令回执）
  → {mac, id, ok, message, image(base64 截图, 仅 screenshot 命令)}

POST {serverUrl}/api/order/create              （激活下单）
  → {mac, months}   ← {"ok":true, "orderId":"...","amount":199.0,"qrImage":"<base64 PNG>"}

POST {serverUrl}/api/order/status              （订单轮询，3 秒）
  → {mac, orderId}  ← {"ok":true,"status":"pending"|"paid","expiresAt":"..."}
```

### 6.3 支持的远程命令

| type | payload | 说明 |
|---|---|---|
| `setUrl` | `{url}` | 更换目标网页，立即导航并保存 |
| `setVocabulary` | `{vocabularies:["gov",...], customVocabulary:"..."}` | 设置词库，引擎热加载无需重启 |
| `setModel` | `{modelSize:"zh2025"\|"large"}` | 切换语音模型，落盘后自动重启生效（自动下载模型） |
| `screenshot` | `{}` | 截取终端完整画面（含设置面板/键盘等覆盖层）回传 JPEG base64 |
| `restart` | `{}` | 重启主程序 |
| `shutdown` | `{}` | 关闭终端（同时停止守护进程，不再自动拉起） |
| `setSettingsPassword` | `{password:"..."}` | 远程设置/清除设置页入口密码（空串=清除） |

安全机制：**未激活（plan≠paid）的终端拒绝执行一切远程命令**；心跳/注册仅上报状态。

### 6.4 生产部署注意

- 后台需公网 HTTPS + ICP 备案（支付平台回调硬性要求）
- 建议注册时下发 `deviceToken`（绑定 MAC 的签名令牌），防止 MAC 穷举伪造终端
- 联调可用 `tools/mock_server.py`（本地 8898 端口，命令通过写 `cmd_queue.json` 注入）

## 7. 守护进程与稳定性

| 机制 | 说明 |
|---|---|
| 进程监控 | 守护进程每 3 秒检测主程序，消失即拉起（5 秒冷却） |
| 心跳卡死检测 | 主程序每 3 秒经命名管道报心跳，连续 3 次缺失判定卡死 → 强杀重启 |
| 内存阈值 | 主程序内存超 1GB（可配）自动重启，防内存泄漏 |
| 重启熔断 | 10 分钟内重启超 10 次 → 暂停 60 秒并 Webhook 告警 |
| 防多开 | 双全局互斥量（主程序/守护进程各自单实例） |
| 崩溃捕获 | 全局异常处理，临终日志经管道上报守护进程 |
| 开机自启 | 计划任务登录后 30 秒启动守护进程 |
| 日志 | `%LocalAppData%\KioskBrowser\logs\`，按天滚动，保留 90 天 |

## 9. 故障排查

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| 页面白屏 | URL 错误 / 网络不通 / 页面脚本错误 | 检查 URL；config.json 设 `"devMode": true` 后 F12 看控制台 |
| 无法自动登录 | 选择器失效 / 页面改版 / 验证码拦截 | 检查目标页面 DOM 更新选择器；日志中有失败计数 |
| 系统键盘仍弹出 | 权限不足无法杀 TabTip | 确认以管理员权限运行 |
| 程序频繁重启 | 页面导致 WebView2 崩溃 / 内存超限 | 查看 watchdog 日志；检查页面死循环 |
| 语音没反应 | 模型未下载完 / 麦克风不可用 | 设置页「模型状态」看是否"已就绪"；Windows 录音机测试麦克风 |
| 语音识别不准 | 档位不合适 / 环境嘈杂 | 换大模型；政务/医疗场景确认词库勾选（中文2025 档热词生效） |
| 候选字空白 | 旧版字典含生僻字 | 升级到 v1.1.0+（已过滤不可渲染字符） |
| 远程命令无响应 | 未激活 / 后台不可达 | 设置页查看激活状态；查看日志 heartbeat 报错 |
